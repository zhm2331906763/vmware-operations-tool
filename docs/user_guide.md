# VCenter管理巡检工具 - 使用说明书

## 版本信息
- 版本: 2.0
- 更新日期: 2026年7月

---

## 一、软件概述

VCenter管理巡检工具是一款用于批量管理VMware vCenter、ESXi主机和虚拟机的自动化工具。支持多vCenter统一管理，提供巡检、批量操作、克隆、证书管理、定时任务等功能。

---

## 二、环境要求

- Python 3.10+
- 依赖库: pyvmomi, openpyxl, pandas, cryptography, paramiko

---

## 三、功能模块总览

| 模块名称 | 功能描述 |
|---------|---------|
| vCenter管理 | 添加、编辑、删除vCenter连接 |
| ESXi主机巡检 | 采集ESXi主机硬件、性能、证书信息 |
| 虚拟机巡检 | 采集虚拟机配置、状态、网络信息 |
| 批量操作 | 10种批量操作类型 |
| 虚拟机克隆 | 从模板批量克隆虚拟机 |
| VCenter证书查询及续订 | VMCA证书查询与续订 |
| 定时巡检 | 自动定时执行巡检任务 |
| 定时开关机 | 定时开关虚拟机 |
| 信息查询 | 智能查询主机和虚拟机信息 |

## 四、详细功能说明

### 4.1 vCenter管理

#### 功能说明
- 添加新的vCenter连接
- 编辑已有vCenter配置
- 删除vCenter连接
- 测试连接有效性

#### 操作步骤
1. 点击"添加"按钮
2. 填写vCenter信息：
   - **IP地址** [必填]: vCenter服务器IP
   - **区域** [选填]: 自定义区域标识
   - **用户名** [必填]: vCenter登录用户名
   - **密码** [必填]: vCenter登录密码
   - **root密码** [选填]: ESXi root密码（用于证书续订）
   - **备注** [选填]: 备注信息
3. 点击"保存"

#### 注意事项
- root密码用于VMCA证书查询及续订功能
- 测试连接可验证账号和网络连通性

### 4.2 ESXi主机巡检

#### 功能说明
采集ESXi主机的硬件配置、性能数据、证书状态等信息。

#### 巡检内容
| 字段名称 | 说明 |
|---------|------|
| vCenter | 所属vCenter地址 |
| 主机名 | ESXi主机名称 |
| 集群 | 所属集群 |
| 状态 | 主机状态（正常/警告/严重/已关机） |
| ESXi版本 | ESXi版本号 |
| 厂商 | 硬件厂商 |
| 型号 | 硬件型号 |
| 序列号 | 设备序列号 |
| CPU型号 | CPU型号信息 |
| CPU主频(GHz) | CPU频率 |
| CPU数量 | CPU物理数量 |
| CPU核心数 | CPU核心总数 |
| 内存(GB) | 内存总量 |
| 运行天数 | 主机运行时长 |
| CPU使用率 | 当前CPU使用率 |
| 内存使用率 | 当前内存使用率 |
| 证书是否即将过期 | 证书状态（是/否） |
| VMK适配器 | VMkernel网络适配器 |
| 证书过期时间 | SSL证书过期日期 |

#### 工具栏功能
- **开始巡检**: 巡检选中的vCenter
- **一键巡检**: 巡检所有vCenter
- **导出Excel**: 导出巡检结果
- **iSCSI**: 导出iSCSI信息
- **端口组**: 导出端口组信息
- **本地硬盘**: 本地硬盘巡检
- **存储巡检**: 存储信息巡检
- **存储巡检-跳过不可访问存储**: 跳过不可访问存储
- **ESXi主机网卡巡检**: 导出主机网卡信息

### 4.4 右键菜单功能

| 功能 | 说明 |

| iSCSI挂载 | 批量挂载iSCSI存储 |

在虚拟机列表中右键点击选中的虚拟机，可执行以下操作：

| 功能 | 说明 |
|-----|------|
| 虚拟机迁移 | 迁移虚拟机到目标主机/存储 |
| 添加网络适配器 | 添加虚拟网卡 |
| 修改备注 | 修改虚拟机备注 |
| 批量重命名 | 批量修改虚拟机名称 |
| 添加硬盘 | 添加虚拟硬盘 |
| CPU内存扩容 | 调整CPU/内存配置 |

### 4.6 表格字段详细说明

#### iSCSI模板 (iscsi.xlsx)
| 字段 | 必填 | 说明 |
|-----|-----|------|
| VC | 是 | vCenter IP地址 |

| 字段 | 必填 | 说明 |

| 迁移后主机 | 选填 | 目标主机（至少填一个） |

| 字段 | 必填 | 说明 |
|-----|-----|------|
| VC | 是 | vCenter IP地址 |
| UUID | 是 | 虚拟机UUID |
| 备注 | 是 | 新的备注内容 |

#### 批量重命名模板 (rename.xlsx)
| 字段 | 必填 | 说明 |
|-----|-----|------|
| VC | 是 | vCenter IP地址 |
| UUID | 是 | 虚拟机UUID |
| 新名称 | 是 | 新的虚拟机名称 |

#### 虚拟机克隆模板 (vm_clone.xlsx)
| 字段 | 必填 | 说明 |
|-----|-----|------|
| VC | 是 | vCenter IP地址 |
| 主机名称 | 是 | 目标ESXi主机 |
| 存储名称 | 是 | 目标数据存储 |
| 文件夹名称 | 选填 | 目标文件夹 |
| 模板名称 | 是 | 源模板名称 |
| 自定义规范名称 | 选填 | 自定义规范 |
| 虚拟机名称 | 是 | 新虚拟机名称 |
| 主机名 | 是 | 虚拟机hostname |
| CPU数量 | 选填 | CPU核数 |
| 内存大小 | 选填 | 内存GB |
| 端口组 | 选填 | 网络端口组 |
| IP地址 | 选填 | 静态IP |
| 子网掩码 | 选填 | 默认255.255.255.0 |
| 网关 | 选填 | 网关地址 |
| DNS1 | 选填 | 主DNS |
| DNS2 | 选填 | 备DNS |
| 硬盘 | 选填 | 硬盘大小(GB)，多个换行 |
| 备注 | 选填 | 备注信息 |

| 字段 | 必填 | 说明 |
|-----|-----|------|

### 4.7 VCenter证书查询及续订

#### 功能说明
- 查询VMCA证书信息
- 执行VMCA证书续订

#### 证书类型
- vCenter证书
- ESXi主机证书
- 其他组件证书

#### 操作步骤
1. 选择vCenter（或"全部vCenter"）
2. 点击"查询证书"查看证书信息
3. 点击"一键续订(VMCA)"执行续订

#### 注意事项
- 需要配置root密码才能执行证书操作
- 续订期间管理面可能短时中断
- 过期证书会用红色标记

### 4.8 定时巡检

#### 支持的任务类型
| 任务类型 | 说明 |
|---------|------|
| ESXi巡检 | 定时采集ESXi主机信息 |
| 虚拟机巡检 | 定时采集虚拟机信息 |
| 存储巡检 | 定时采集存储信息 |
| 存储巡检-跳过不可访问存储 | 跳过不可访问存储的巡检 |

#### 调度方式
- **每天**: 每天定时执行
- **每周**: 指定星期几执行
- **仅一次**: 执行一次后自动禁用

#### 操作步骤
1. 点击"添加任务"
2. 填写任务配置：
   - 任务名称 [必填]
   - 任务类型 [必填]
   - 调度方式 [必填]
   - 执行时间 [必填] (格式: HH:MM)
   - 执行星期 [每周时必填]
   - 保存路径 [选填]
3. 点击"保存"

#### 右键菜单
- **立即执行**: 立即执行任务
- **编辑**: 修改任务配置
- **删除**: 删除任务

---

### 4.9 定时开关机

#### 功能说明
定时开启或关闭虚拟机电源。

#### 目标输入格式
支持以下格式，每行一个：
- UUID
- 虚拟机名称
- IP地址
- 逗号分隔的多个标识

#### 操作步骤
1. 点击"添加任务"
2. 填写任务配置：
   - 任务名称 [必填]
   - 动作 [必填]: 开机/关机
   - 调度方式 [必填]
   - 执行时间 [必填]
   - 目标输入 [必填]: 输入虚拟机标识
3. 点击"保存"

### 4.10 信息查询

#### 查询范围
- ESXi主机信息
- 虚拟机信息

#### 支持的查询条件
| 查询类型 | 示例 |
|---------|------|
| 虚拟机IP | 192.168.1.100 |
| 虚拟机名称 | vm-test-01 |
| ESXi主机名 | esxi-01 |

1. 在查询框输入条件
2. 点击"查询"或按回车
3. 查看查询结果

#### 结果展示
- 显示匹配的主机/虚拟机信息
- 包含区域、配置、状态等完整信息

## 五、常见问题

### Q1: 连接vCenter失败
- 检查网络连通性
- 确认用户名密码正确
- 检查vCenter服务状态

### Q2: 证书续订失败
- 确认已配置root密码
- 检查SSH服务是否开启
- 查看执行日志定位问题

### Q3: 批量操作失败
- 检查Excel模板格式
- 确认必填字段已填写
- 查看执行结果中的错误详情
